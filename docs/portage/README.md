# Portage vers l’app sœur (`pilotage_studios`)

Le widget Grist est la **référence produit** des parcours utilisateurs. L’app web solo ne suit **que** si une issue `portage-from-grist` est ouverte côté `pilotage_studios`.

Voir aussi [`AGENTS.md`](../AGENTS.md) (Grist-first, handoff).

## Quand créer une fiche

À la fin d’une PR widget qui change un comportement utile aussi dans l’app solo : cocher la case PR *Portage app solo* → **fiche créée**. Sinon **N/A**.

Copier [`_TEMPLATE.md`](_TEMPLATE.md) → `docs/portage/<module>-<slug>.md`.
